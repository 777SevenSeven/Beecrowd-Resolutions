## 📁 Estrutura de Pastas

A estrutura segue a seguinte hierarquia organizada:

```
Beecrowd-Resolutions/
├── <Categoria>/                     # Iniciante, Strings, SQL, Ad-Hoc, Paradigmas
│   ├── Nivel-<1-10>/               # Subdivisão por Nível de Dificuldade
│   │   ├── <ID>/                   # Pasta do exercício quando resolvido em múltiplas linguagens/tentativas
│   │   │   ├── <ID>.cpp
│   │   │   ├── <ID>.py
│   │   │   └── <ID>.java
│   │   └── <ID>.<ext>              # Arquivo direto quando resolvido em uma única linguagem
```

Todos os arquivos de código possuem um **cabeçalho padronizado** com metadados do exercício:
```c
/*
 * Beecrowd | 1001 - Extremamente Básico
 * Categoria: Iniciante | Nível 4 | Assunto: Sequencial
 * Link: https://judge.beecrowd.com/pt/problems/view/1001
 */
```
