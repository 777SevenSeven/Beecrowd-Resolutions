## 📁 Estrutura do Repositório

O repositório está organizado prioritariamente por **categoria de exercícios**.
Quando o mesmo exercício foi resolvido em **diferentes linguagens** ou possui **múltiplas tentativas aceitas**, ele é agrupado em uma **pasta com o ID do exercício**. Caso o exercício tenha sido resolvido em uma única linguagem, o arquivo fica localizado diretamente na raiz da pasta da categoria.

Exemplo da estrutura:

```
Beecrowd-Resolutions/
├── Iniciante/
│   ├── 1001/
│   │   ├── 1001.c
│   │   ├── 1001.cpp
│   │   ├── 1001.cs
│   │   ├── 1001.java
│   │   ├── 1001.js
│   │   └── 1001.py
│   ├── 1002.py
│   └── 1973/
│       ├── 1973_1.cpp
│       ├── 1973_2.cpp
│       └── 1973.c
├── SQL/
│   ├── 2602.sql
│   └── ...
├── Strings/
│   ├── 1024.py
│   └── ...
└── ...
```
